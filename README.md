# Telegram Voice-First Gemini Bot (`rixed318/tg-bot`)

Голосовой ИИ-собеседник для Telegram-группы **«Блендер»** и личных диалогов участников.

## Ключевые возможности

1. **Общение исключительно голосовыми сообщениями (OGG/Opus)**
   - Бот никогда не отвечает разговорным текстом и не оставляет служебные статусные сообщения («Смотрю контекст…»).
   - Пока модель думает и генерирует звук, в чате отображается нативный статус `Записывает голосовое сообщение…` (`record_voice`).
   - Локальный движок клонирования голоса: **`F5-TTS` (русская эмоциональная модель) + `RUAccent`** (автоударения) на GPU с фолбэком на `Edge-TTS`.
   - Поддержка собственного голоса через `/setvoice` в ЛС бота или файл `voices/custom.wav`.

2. **Умный триггер + свой флаг + батчинг сообщений**
   - Gateway записывает **каждое** сообщение группы в базу.
   - Входящие голосовые/видеосообщения участников расшифровываются через `faster-whisper` и сохраняются в постоянную историю.
   - Для сообщений без прямого обращения модель сначала запускает триггер-классификатор и сама выставляет флаг `decision_flag` (`reply` или `skip`) и причину `decision_reason`.
   - Если сообщение пропущено (`skip`), оно остаётся в буфере неотвеченных сообщений после последнего ГС бота — когда накопится повод (например, 2–4 сообщения подряд), бот отвечает **одним цельным голосовым**, учитывая сразу все эти сообщения, и сдвигает отметку обработанного окна.

3. **Неограниченный контекст + Google Диск**
   - Из выборки контекста убраны любые искусственные лимиты (`limit 40` удалён): вся история переписки с первого сообщения передаётся воркеру в `full-context.jsonl`.
   - Полные снимки `history.jsonl` (вместе с расшифровками ГС, флагами триггера и голосовыми ответами бота) синхронизируются на Google Диск (`gdrive:Тау бао — медиа/<scope>/context/history.jsonl`) через `rclone` с отслеживанием SHA-256.
   - Входящие медиа, сгенерированные картинки и исходящие голосовые архивируются в соответствующие месячные папки на Google Диске.

4. **Два режима 2D-аватаров**
   - В `/commands` → «Отображение речи» можно переключаться между обычными качественными pixel-art аватарами и сохранённым «ржачным» фото-режимом.
   - Режим не зависит от переключателя «Кружочки / ГС»: при отключённых кружочках бот продолжает отправлять обычные голосовые сообщения.

5. **Локальные singing-cover по присланному треку**
   - Просьбы «спой / перепой / сделай кавер / под бит» с аудиофайлом обходят обычный LLM-ответ и запускают детерминированный аудиопайплайн.
   - `Demucs` отделяет исходный вокал, `Seed-VC` переносит его мелодию, слова и тайминг на выбранный профиль голоса, после чего вокал сводится с исходным минусом.
   - Результат автоматически делится на части по 55 секунд и отправляется цепочкой кружков с выбранным 2D-аватаром. Поэтому трек длиной 2:21 даёт три кружка.
   - Whisper внутри Seed-VC используется как акустический энкодер, а не для транскрибации; обычная расшифровка бота по-прежнему работает через `faster-whisper`.

## Быстрый старт (разработка и тесты)

```bash
cd /home/rus/dev/tg-bot
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -e ".[worker,dev]"
.venv/bin/pytest
```

## Деплой

- VPS gateway и очередь: `bash deploy/deploy_vps.sh`
- Локальный воркер: `deploy/rixed-joke-gemini.service` (`~/.config/systemd/user/rixed-joke-gemini.service`)
